### Последовательность действий ###

1. Создание пользователей [create-accounts](create-accounts.sh)
2. Создание ролей [create-roles](create-roles.sh)
3. Связывание [bind-roles](bind-roles.sh)

| Роль | Права роли | Группы пользователей |
| --- | --- | --- |
| analyst | - Доступ на чтение к подам, сервисам, настройкам в namespace</br> - Доступ на чтение логов | Аналитики |
| developer | - Доступ к подам, сервисам, настройкам в namespace</br> - Выполнение команд на подах | Разработчики |
| engineer | - Доступ к подам, сервисам, настройкам в namespace</br> - Мониторинг событий</br> - Выполнение команд на подах | Инженеры по эксплуатации |
| devops | - Полный доступ ко всем ресурсам в namespace | DevOps-инженеры |
